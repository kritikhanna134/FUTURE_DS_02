# Customer Churn & Retention Analysis

## Project Overview
This project analyzes customer churn and retention using Microsoft Power BI as part of the Future Interns Data Science & Analytics Internship — Task 2.

## Objective
To understand customer churn patterns, evaluate retention performance, identify factors associated with customer loss, and recommend strategies to improve customer retention.

## Tools Used
- Power BI
- Power Query
- DAX
- SaaS Customer Churn Dataset

## Key Analysis
- Total customers and churned customers
- Churn rate and retention rate
- Churn patterns by subscription plan
- Customer retention and churn drivers
- Customer lifetime analysis

## Key Metrics
- Total Customers: 500
- Churned Customers: 110
- Churn Rate: 22%
- Retention Rate: 78%

## Business Recommendations
- Identify customer groups with higher churn rates.
- Investigate common churn reasons and customer feedback.
- Review subscription plans and customer support experiences.
- Develop targeted retention strategies for at-risk customers.
